2.如何解决输出是乱码的问题
# 修复 PowerShell 中文显示（每次新开窗口都要执行）
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8

# 然后正常调用
$body = @{
    task_id = "T001"
    remark  = "触发测试"
} | ConvertTo-Json

Invoke-RestMethod -Uri "http://127.0.0.1:8090/api/trigger/auto-test" `
    -Method Post `
    -ContentType "application/json" `
    -Body $body

[Console]::OutputEncoding = [System.Text.Encoding]::UTF8

$body = @{
    task_id = "T001"
    remark  = "触发测试"
} | ConvertTo-Json
========================================================================
# 用 Invoke-WebRequest 替代，手动用 UTF-8 解码
$resp = Invoke-WebRequest -Uri "http://127.0.0.1:8090/api/trigger/auto-test" `
    -Method Post `
    -ContentType "application/json" `
    -Body $body

# 关键：用 UTF-8 解码原始字节
$jsonStr = [System.Text.Encoding]::UTF8.GetString($resp.RawContentStream.ToArray())
$result = $jsonStr | ConvertFrom-Json
$result
===============================================================================
如果不想每次都手动设置，可以把编码设置加入 PowerShell 配置文件：
# 打开 PowerShell 配置文件（没有会自动创建）
notepad $PROFILE

# 在文件末尾加入这一行：
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
